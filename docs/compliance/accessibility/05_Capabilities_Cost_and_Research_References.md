## Cost policy for this project

The chosen policy is **quality and cost optimization within the existing paid setup**. No numerical project budget was supplied. The prompts preserve existing controls, require estimates before bulk/API work, and reserve new credit purchases, billing changes, limit increases, infrastructure, or publication for explicit authorization.

AI Studio is not uniformly free in every configuration: Google says usage through a linked paid key/project can incur charges. Do not assume a Gemini consumer subscription or a Cloud promotion covers this work. Verify the active project, relevant prices, remaining capacity, and controls. Sources: [billing](https://ai.google.dev/gemini-api/docs/billing), [pricing](https://ai.google.dev/gemini-api/docs/pricing).

Compare total cost: extraction/indexing + input/output/thinking tokens + search/tool charges + optional media + repeated revisions + any hosting/export work. Report actual measurements only when visible. Do not invent a percentage of credits saved.

Practical savings come from a shared content/design system, a representative pilot, task-specific source sections, compact checkpoints, selective research tools, smaller models for routine passes when quality holds, and changes limited to affected assets.

**Uploads versus caching:** Reusing an uploaded file can reduce repeated transfer, but it does not guarantee cheaper inference. Files API uploads expire; the documented retention is 48 hours. Cache reuse is separate and depends on actual eligibility/hits. Sources: [Files API](https://ai.google.dev/gemini-api/docs/files), [caching](https://ai.google.dev/gemini-api/docs/caching).

**API-only optimization options:** Google's Batch API documentation describes asynchronous nonurgent work at 50% of standard cost, with a target turnaround of 24 hours. Use it only if automation volume and supported features justify setup. Caching support differs by model and API; explicit caching is not universally available, and storage can add cost. Sources: [Batch API](https://ai.google.dev/gemini-api/docs/batch-api), [caching](https://ai.google.dev/gemini-api/docs/caching), [pricing](https://ai.google.dev/gemini-api/docs/pricing).

## Privacy and authorization

Check current Gemini/AI Studio service terms and institutional permission before uploads. Google distinguishes unpaid and paid service data treatment; unpaid terms caution against sensitive/confidential/personal submissions. Paid service treatment still does not establish that a particular institutional record is authorized for upload. This preparation used local files locally and did not upload them to Google. Sources: [Gemini API terms](https://ai.google.dev/gemini-api/terms), [billing/data handling](https://ai.google.dev/gemini-api/docs/billing).

## Accessibility authorities

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/): proposed web project baseline, Level AA. Check the institution's governing requirements separately.
- [WCAG2ICT](https://www.w3.org/TR/wcag2ict/): informative application guidance for non-web documents/software.
- [Microsoft PowerPoint guidance](https://support.microsoft.com/en-us/accessibility/powerpoint/make-your-powerpoint-presentations-accessible-to-people-with-disabilities): authoring, reading order, titles, alternatives, media, and final-file checks.
- [Microsoft Word guidance](https://support.microsoft.com/en-us/accessibility/word/create-more-accessible-word-documents): document structure, links, images, and tables.
- [Contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html), and [target sizing](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html): specific explanations for measured/testable checks.

Use the completed orchestrator for the project checklist. These sources do not supply an automated certificate for any generated file.
