These guides are supplied reference inputs, not proof of implementation or institutional approval.

The checklist's 15-minute timeout, AES-256, WORM logging, alert timings and example retention periods are project criteria to confirm with policy owners, not universal technical requirements imposed by FERPA. Apply the governing [Department of Education regulations](https://studentprivacy.ed.gov/ferpa), including recordkeeping exceptions, to the actual use case.

Cloud evidence must follow the selected deployment model and [Azure shared responsibility](https://learn.microsoft.com/en-us/azure/security/fundamentals/shared-responsibility). For concrete cloud preparation, use [Key Vault security guidance](https://learn.microsoft.com/en-us/azure/key-vault/general/secure-key-vault) and [Azure Monitor diagnostic settings](https://learn.microsoft.com/en-us/azure/azure-monitor/data-collection/diagnostic-settings). Resource logs need configured destinations; a Log Analytics workspace alone does not establish immutable storage.
